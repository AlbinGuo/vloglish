# App Store 正式上架 · 准备与审核清单

> 配合 [IOS_BUILD.md](./IOS_BUILD.md) 使用。TestFlight 能上传只是第一步，**正式上架**还要在
> App Store Connect 里补齐商务、内购、元数据、隐私与审核信息。
> 下面「审核备注模板」可直接复制粘贴到 App Store Connect → App 审核 → 备注。

---

## 一、商务前置（卖会员必须先做）

- [ ] 签《付费 App 协议》（Paid Apps Agreement）：App Store Connect → **协议、税务和银行业务**
- [ ] 填写 **银行账户** 与 **税务信息**（否则内购无法上架 / 用户无法付款）

## 二、内购（IAP）配置

代码里的 product id：`week / quarter / year / forever`（见 `frontend/src/pages/PricingPage.vue` 的 `APPLE_PRODUCT_IDS`）。

- [ ] 在 App Store Connect → **App 内购买项目** 创建 4 个商品，**product id 与代码完全一致**：
  - `week` / `quarter` / `year` → **自动续期订阅**，放进**同一个订阅组**
  - `forever` → **非消耗型**
- [ ] 每个商品填：价格档、本地化（中/英）、**审核截图**
- [ ] **首个内购必须随这个 App 版本一起提交审核**（不能单独先审）
- [ ] 订阅价格与免费试用说明要和 App 内展示一致

## 三、元数据

- [ ] App 名称（确认 `Vloglish` 未被占用）、副标题、描述、关键词
- [ ] 类别（教育 / 参考资料等）、**年龄分级**问卷、版权
- [ ] 截图：iPhone 6.9"（或 6.5"）必填；若支持 iPad 还需 iPad 截图 —— **真实展示功能**
- [ ] App 图标：1024 无 alpha（本项目已自动处理）

## 四、隐私与合规

- [ ] **隐私政策 URL**：用本项目的 `/privacy` 页面（见下「URL 说明」）
- [ ] **支持 URL**：可用官网或 `/download` 页面
- [ ] **App 隐私营养标签**：按实际采集填写（邮箱、使用数据、购买记录），必须与隐私政策一致
- [ ] **账号注销**：已实现（关键，5.1.1(v)），入口路径见下方审核备注
- [ ] 出口合规：若只用 HTTPS 标准加密，`ITSAppUsesNonExemptEncryption = NO`（无需提供证明）

### URL 说明（隐私政策 / 用户协议）

已在 App 内新增页面：
- 隐私政策：`/privacy`（`frontend/src/pages/PrivacyPolicyPage.vue`）
- 用户协议：`/terms`（`frontend/src/pages/TermsPage.vue`）

Web 版用 **History 路由**，公网域名若已配置 SPA 回退，填：
```
https://<你的域名>/privacy
https://<你的域名>/terms
```
若服务器未配置 SPA 回退（刷新 404），改用哈希地址：
```
https://<你的域名>/#/privacy
```

> ⚠️ 提交前请把页面里的 `<请填写你的联系邮箱>` 换成真实联系邮箱。

## 六、中国大陆区（若上架中国区）

- [ ] 中国区上架需要 **ICP 备案号**（Apple 会校验）
- [ ] 付费会员 / 教育内容可能需相应资质
- [ ] 若暂无备案：在「价格与销售范围」里**去掉中国大陆**，先上架其他地区，备案完成后再开

## 七、提交步骤

1. 上传构建（本项目的 TestFlight 工作流会自动上传）
2. App Store Connect → 版本 → **选择该构建**
3. 回答**出口合规**（是否使用加密）
4. 填好上面一~四节的全部信息
5. **添加用于审核的构建并提交审核**
